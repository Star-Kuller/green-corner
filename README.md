# Зелёный угол

Пятистраничный справочник по комнатным растениям. Публичный сайт: https://star-kuller.github.io/green-corner/

## Страницы
- index.html — главная.
- catalog.html — шесть растений и источники.
- selector.html — подбор по трём группам условий.
- care.html — руководство и ботанические источники.
- materials.html — два текстовых материала для скачивания.

## Размещение
Статические HTML, CSS, JavaScript и SVG. Сборка и серверная часть не требуются. GitHub Pages: ветка main, каталог / (root). Все локальные ссылки относительные и поддерживают адрес проекта /green-corner/.

## Аналитика
Код LiveInternet установлен в подвале всех пяти страниц. Использован предоставленный сервисом видимый счётчик 88×31 (тип t11.16) без изменения его кода. Регистрируемый адрес: https://star-kuller.github.io/green-corner/.

Sber Ads: счётчик 7753263 установлен в начале body всех пяти страниц. После инициализации вызывается внутреннее событие green-corner:sber-ready. Виджет Топ-100 выводится документированным методом drawLogoTo в подвале. Действия plant_match_complete и guide_download передаются через trackEvent; до готовности SDK они ожидают в памяти страницы.

MyTracker пока не подключён: нужен настоящий код зарегистрированного веб-счётчика.

В assets/app.js предусмотрены два смысловых события:
- plant_match_complete — успешное завершение подбора; параметры light, care, space, plant.
- guide_download — нажатие ссылки скачивания; параметр resource. Это клик по ссылке, а не подтверждение сохранения файла.

Функция window.greenCornerTrack вызывает событие DOM green-corner:event. Последние 100 событий текущей страницы доступны в window.greenCornerEvents для проверки; после перезагрузки они исчезают. Эта очередь сама по себе не отправляет события на сервер. LiveInternet и Sber Ads отдельно передают просмотры страниц. Пользовательские события подключены к Sber Ads; интеграция MyTracker ещё не выполнена. Интеграцию нужно добавлять отдельно по документации каждого сервиса, не подменяя её локальной очередью.

Подбор основан на прозрачной таблице предпочтений и не заменяет требования конкретного вида или сорта. Результаты не содержат вымышленных отзывов или статистики. Иллюстрации SVG созданы для проекта. Ботанические источники указаны на сайте.
